Состояние проекта

Регистрация и чат используют сервер. Глобус использует CesiumJS; для полноценного рельефа нужен токен Cesium ion. Голосовая передача, генератор изображений и запись изменений GitHub ещё не реализованы полностью. Приложение не будет менять репозиторий без явного подтверждения.
